# Breakthrough Advertising

Apply Eugene Schwartz's 1966 copywriting system as a universal base layer for market diagnosis, headline development, campaign planning, copy audits, and copy strengthening.

## Quick Start

1. Open `guidelines.md`.
2. Pick the use case, symptom, or decision-tree branch that matches the assignment.
3. Load only the referenced files.
4. Apply Schwartz's terminology and original examples as the base layer; leave brand-specific adaptation to a separate adapter skill.
